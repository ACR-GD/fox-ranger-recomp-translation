# Enhanced Arranged Soundtrack Directory

Place high-quality arranged soundtracks, modern remixes, or CD audio rips here in `.ogg` (Ogg Vorbis) or `.wav` (PCM) format.

When enabled in the Fox Ranger Mission Control Launcher (`foxrt`), the engine will seamlessly stream these arranged tracks in real-time, mixed with authentic sound effects and voice clips.

## Track Naming Conventions

You can name tracks either by **Scene Name** or by **Track ID**:

### By Scene Name:
- `intro.ogg` / `intro.wav` — Opening intro cinematic
- `title.ogg` / `title.wav` — Title & Main Menu
- `stage1.ogg` / `stage1.wav` — Stage 1 BGM
- `boss.ogg` / `boss.wav` — Boss Battle BGM
- `stage2.ogg` / `stage2.wav` — Stage 2 BGM
- `stage3.ogg` / `stage3.wav` — Stage 3 BGM
- `stage4.ogg` / `stage4.wav` — Stage 4 BGM
- `stage5.ogg` / `stage5.wav` — Stage 5 BGM
- `stage6.ogg` / `stage6.wav` — Stage 6 BGM
- `stage_clear.ogg` / `stage_clear.wav` — Stage Victory Jingle
- `ending.ogg` / `ending.wav` — Ending Credits
- `gameover.ogg` / `gameover.wav` — Game Over Screen

### By Track ID:
- `track_01.ogg` .. `track_20.ogg` (or `track01.ogg`, `01.ogg`, etc.)

If an arranged track file is not present for a specific stage or jingle, the engine automatically falls back to authentic Nuked-OPL3 synthesis with zero interruption.
